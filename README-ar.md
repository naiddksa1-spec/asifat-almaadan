# عاصفة المعدن

عرض تجريبي عالي الجودة لقتال جوي في المتصفح، مستوحى من أسلوب ألعاب الـ dogfight في الوديان الصخرية — **بعلامة أصلية** «عاصفة المعدن» (بدون شعار أو علامة Metalstorm التجارية).

## التشغيل

```bash
cd /workspace/metalstorm-like
python3 -m http.server 8765
```

ثم افتح في المتصفح:

**http://localhost:8765/**

أو افتح الملف مباشرة:

`file:///workspace/metalstorm-like/index.html`

(يفضّل خادم محلي لضمان تحميل Three.js من CDN.)

Three.js `r160` مضمّن محلياً في `vendor/three.min.js` (مع احتياطي CDN).

## الميزات

- **حظيرة طائرات**: اختيار من ٥ مقاتلات (إف-١٥، إف-٢٢، سو-٥٧، جيه-٢٠، ميراج ٢٠٠٠) مع إحصائيات عربية
- **مباراة ٥ ضد ٥** ضد بوتات + وضع تدريب أقصر
- **منظور ثالث** خلف الطائرة مع ميل الكاميرا عند الانعطاف
- **وادي صخري إجرائي** (منحدرات، أعمدة، ماء، ضباب، سماء متدرجة)
- **أسلحة**: مدفع رشاش، صواريخ موجّهة، شعلات خداع
- **رادار دائري** + مؤشرات أصدقاء/أعداء + قفل هدف
- **واجهة عربية كاملة** (أرقام عربية، تسميات، نتائج المباراة)
- **لوحة متصدرين** تجريبية داخل القائمة
- **لمس + لوحة مفاتيح**: عصا افتراضية، أزرار انعطاف، WASD/أسهم، Space مدفع، F صاروخ، X شعلات، Shift احتراق خلفي

## التحكم

| إدخال | وظيفة |
|--------|--------|
| WASD / أسهم | توجيه |
| عصا لمس (أسفل اليسار) | توجيه على الجوال |
| ‹ › | انعطاف سريع |
| Space / زر المدفع | إطلاق مدفع |
| F / زر الصاروخ | صاروخ موجّه |
| X / زر الشعلات | شعلات مضادة |
| Shift | احتراق خلفي |
